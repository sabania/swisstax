### Zinssätze

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **Rückerstattungszins** | 4.0% | 4,5% | 4,75% | 4% | 4% | 3% | 3% |
| **Verzugszins** | 4.0% | 4,5% | 4,75% | 4% | 4% | 3% | 3% |
| **Vergütungszins** | 0.0% | 0,75% | 1,25% | 0% | 0% | 0% | 0% |
