> HWP BWP · III.2.3 Grenzen und Gültigkeit · Rz 49 · S. 148

Grenzen und Gültigkeit

Die Aussage aus einer Softwareprüfung bezieht sich immer auf eine definierte Version der
Software in einer bestimmten Testumgebung und einen bestimmten Satz an Kriterien.
Im Anwendungsfall kann die Konstellation einer beim Benutzer der Software vorhandenen Plattform wesentlich von der Testumgebung abweichen und unter Umständen das
Verhalten der Software resp. ihre Funktionalität beeinflussen. Weiter kann dieses Verhalten auch durch eine unsachgemässe Implementierung oder nicht korrekte Bedienung
beeinflusst werden.
Die Aussage des Zertifikats zu Softwareprodukten ist für eine abweichende Situation
nur bedingt anwendbar. Falls eine Aussage eines Zertifikats über einen Zeitraum verwendet werden soll, muss beim Benutzer geprüft werden, ob die zertifizierte Softwareversion in einer passenden Konstellation der Benutzerumgebung über den gesamten Zeitraum zum Einsatz kam.
Der Benutzer einer Software sieht sich in der Praxis oft in der Situation, dass durch den
Softwareentwickler Änderungen am eingesetzten Softwareprodukt vorgenommen werden. Der Benutzer der Software kann sich nach wesentlichen Änderungen nur noch eingeschränkt auf die Aussagen der Softwareprüfung und des Zertifikats stützen.
Anbieter von Software beauftragen nach solchen Änderungen deshalb in der Regel Folgeprüfungen, auch Delta-Zertifizierungen genannt. Diese fokussieren auf die Änderungen im Vergleich zu einer bereits geprüften Version der Software.
